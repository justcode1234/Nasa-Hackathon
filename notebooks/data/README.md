# Reviewed datasets go here

No training corpus is bundled. The notebooks document the JSONL schema for
`intent_examples.jsonl` and `llm_examples.jsonl`. Include source/license, group IDs,
human review and out-of-scope examples. Keep private farmer information out of Git.
Source-linked facts generated from the catalog are grounding records, not labelled
training/evaluation examples. Do not turn the test fixtures into scientific data.
